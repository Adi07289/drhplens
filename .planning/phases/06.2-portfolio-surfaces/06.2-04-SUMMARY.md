## Deviations from Plan
The plan was executed as written. One test-authoring bug was caught and fixed before the RED commit:

**1. [self-caught] `str.lstrip("./")` mangled a link path in the test**
- **Found during:** Task 1 (RED run diagnosis)
- **Issue:** `"./.env.example".lstrip("./")` strips a *character set*, not a prefix → `"env.example"`, so the link-resolver falsely reported `.env.example` broken even though it exists.
- **Fix:** dropped the `lstrip` and let `Path` normalize the leading `./` (`(REPO_ROOT / t).resolve()`), with a comment explaining the trap. The link-resolver then passed on the (still-stub) README, leaving only the intended RED failures.
- **Committed in:** `188e0fd` (RED test commit, pre-fix squashed into the same commit).

**Total deviations:** 1 (test bug, self-caught). **Impact:** none on scope; the fix hardened the link audit.
