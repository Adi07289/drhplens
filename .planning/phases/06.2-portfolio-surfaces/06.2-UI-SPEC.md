# Phase 6.2 — UI Design Contract

> Visual + interaction contract for the three portfolio surfaces (LAND-01 `/methodology`
> hero, FAILGAL-01 `/failures`, OPS-03 committed dashboard). Reuses the established
> **Graphite + Amber** dark "research-terminal" design system; adds two new components
> (architecture-diagram hero, failure card) approved via preview on 2026-08-01.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Streamlit + hand-authored CSS in `app/static/drhplens.css`) |
| Preset | Graphite + Amber dark "research terminal" (established; `:root` tokens) |
| Component library | none (Streamlit primitives + `st.container(border=True)` cards + inline SVG) |
| Icon library | inline SVG only (survives the Streamlit sanitizer); no icon font added |
| Font | IBM Plex Serif (display/titles) · IBM Plex Sans (body) · IBM Plex Mono (figures/labels/diagram) |

**Reuse mandate:** new surfaces reuse existing `.drhp-*` classes + `:root` tokens. New CSS is
additive (`.drhp-arch-*`, `.drhp-fail-*`), injected every run via the existing non-idempotent
`load_global_css` path. No new palette, no gradients (glow flattened per the design system).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (~60%) | `#16171A` (`--drhp-bg`) | page ink |
| Secondary (~30%) | `#1E2024` / `#26282D` (`--drhp-surface` / `-secondary`) | cards, nodes, lanes, chips |
| Border | `#33363C` (`--drhp-border-subtle`) | node/card/lane hairlines |
| Text / muted | `#ECECEA` / `#9A9BA0` | primary text / captions, labels |
| Accent (~10%) | `#E0A24E` / `#E6AC5C` (`--drhp-accent` / `-link`) | see reserved list |
| Destructive | **N/A** | honesty invariant — no red/green/destructive verdict color anywhere |

**Accent reserved for:** eyebrow/lane labels; diagram connectors (→); the single amber-filled
"cited answer" output node; the failure-card left-rule + surface chip + the Actual-column
left-rule; the report/demo links. **Never** used to encode good/bad. `open` vs `mitigated`
status renders in **muted mono with a dashed neutral border** — not color.

## Component Contracts (new — approved via preview 2026-08-01)

### C1 — Architecture-diagram hero (`.drhp-arch-*`, LAND-01)
- **Horizontal**, 3 lanes: `Ingest` → `Retrieve · Reason` → `Extract · Forecast · Answer`,
  separated by amber `→` connectors. Deliberately distinct from `/how_it_works`' vertical
  `.drhp-flow` (resolves the "two pages look identical" design TODO — methodology = denser
  technical/terminal language).
- Each node: mono label + muted sub-label. The LangGraph node shows agent sub-steps
  (`gate1 · generate · scrub · cite-check`) as inline mono micro-chips.
- The terminal node ("Cited, calibrated answer ✓") is the **single** amber-filled node.
- **Honesty:** every node names the REAL stack — asserts `PyMuPDF`/`pdfplumber`/`Qdrant`/
  `LangGraph`/`Instructor`/`MAPIE` present, `Docling` absent.
- Rendered as inline HTML/CSS (sanitizer-safe: `st.markdown(..., unsafe_allow_html=True)` with
  a single `<div class="drhp-arch">…`; inline SVG for connectors if needed — SVG survives).

### C2 — Failure card (`.drhp-fail-*`, FAILGAL-01)
- `st.container(border=True, key="drhpcard-fail-{id}")` (the lifted-depth card hook), amber
  **left-rule** (3px) for scannability (not a verdict color).
- Row 1: surface chip (`forecast|rag|extraction`, mono uppercase, bordered pill) + `category: …`
  (muted mono) + right-aligned neutral status pill (dashed border, muted).
- Serif title (the failure in one line). Then Expected | Actual as a two-column mono grid —
  Expected has a neutral left-rule, Actual an amber left-rule (attention, not "bad").
- Post-mortem: muted body under a hairline, prefixed by a mono `POST-MORTEM` label.
- Gallery = vertical stack of cards, grouped/orderable by surface; ≥10 cards.

### C3 — Committed dashboard (OPS-03)
- Standalone HTML mirrors the same tokens **inline** (self-contained, no external URLs). Same
  honesty invariant: mono figures, no red/green; `faithfulness = not measured` rendered verbatim.
