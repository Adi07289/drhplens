## Decisions Made
- **Local empty-state constants in `ui/failures.py`** (mirrored in `ui/copy.py`): importing `ui.copy` into the renderer would add `ui` to its import set and break the P19 AST-import allowlist test. The renderer keeps local `_EMPTY_HEADING`/`_EMPTY_BODY` (byte-identical to the copy.py source-of-truth), exactly as `ui/eval_inline.py` keeps a local `_EMPTY_FALLBACK`.
- **`by_design` optional boolean** drives the `OPEN · BY DESIGN` label so `status` can stay strictly `{open, mitigated}` and the schema+count test stays simple; `mitigated` always renders `MITIGATED` (UI-SPEC has no "MITIGATED · BY DESIGN").
- **HTML `id="drhp-fail-{id}"` deep-link anchor** per card — makes each failure individually addressable and makes the in-memory filter observable to the render test (an `id=` attribute, never a `class`, so it does not trip the `.drhp-fail-*`-only class scan).

## Deviations from Plan

The plan was executed as written. One implementation detail resolved a latent conflict between two hard constraints:

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Empty-state copy kept local in `ui/failures.py` instead of imported from `ui/copy.py`**
- **Found during:** Task 2 (building `render_failures`)
- **Issue:** The plan's Task 2 text says to emit the empty-state "using the UI-SPEC copy from `ui/copy.py`", but `from ui.copy import …` adds `ui` to the module import set, which the Task-1 AST-import-allowlist test (`{__future__, html, json, pathlib, yaml, streamlit}`) forbids — the primary P19 isolation control would fail.
- **Fix:** Defined `_EMPTY_HEADING`/`_EMPTY_BODY` as local module constants in `ui/failures.py` (the exact posture of `ui/eval_inline.py::_EMPTY_FALLBACK`), and ALSO added the same strings to `ui/copy.py` as the canonical scrubber-checked copy sink for the page chrome. The two are byte-identical.
- **Files modified:** ui/failures.py, ui/copy.py
- **Verification:** `test_read_only_isolation_allowlist` PASSES; `test_copy_no_banned_tokens.py` PASSES (23).
- **Committed in:** `a393bc2` (Task 2 commit)
