### 2. [Rule 2] C1 hero copy kept inline in the page, not in `ui/copy.py`
- **Plan text:** Task 1 said to add the hero copy to `ui/copy.py`.
- **Reality:** the LAND-01 render test source-audits the PAGE file (`PAGE.read_text()`) for the real pipeline names; if the copy were imported from `ui/copy.py` the page source wouldn't contain the literals and the tests couldn't pass. The page is already 100% inline HTML.

**Also:** replaced the pre-existing `.drhp-hero2` title hero (not only the RAG diagram) so the page leads with one coherent systems-breadth hero rather than two stacked H1s; and replaced (not merely dropped) the Docling stack chip with the real parsers.
