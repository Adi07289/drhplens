## Decisions Made

- **Deterministic, pipeline-free generator:** stdlib-only, no timestamps, no network — byte-identical rebuild over the same committed artifacts. This lets the parity test guard against silent metric drift.
- **Inline faithfulness sentinel:** the `-1.0 → "not measured"` rule was re-implemented inline rather than imported from the app render layer (which would pull streamlit), keeping the generator dependency-light and passing its own isolation grep.
- **Extraction F1 hardcoded `0.000` + ref:** no machine-readable extraction JSON exists (RESEARCH Open-Q#2), so the literal is cited inline to `eval/reports/2026-06-25-extraction-f1.md` and pinned by the parity test.
- **R² at 2 decimals (`-0.01`):** the raw `-0.0095` renders as a `0.00`-containing substring which would collide with the "no fabricated 0.00 faithfulness" honesty assertion; 2-decimal `-0.01` is honest (near-zero) and collision-free.
