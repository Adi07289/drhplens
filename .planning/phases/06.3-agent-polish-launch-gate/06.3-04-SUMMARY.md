## Decisions Made
- **Envelope-only gate:** the committed deterministic suite asserts tokens + structure (scrubber, disclaimer, no leak, bounded hops, single-IPO, honest-partial). Advice-by-implication is explicitly a separate REPORTED lane (AI-SPEC §5) — the gate does not claim to catch a clean-token lean.
- **Category-driven fakes + optional row keys:** rows carry the four mandated keys plus a few honest optional hints (`implication`, `mode`, `inject`, `tools`, `expect_not_disclosed`) so `fake_routing`/`fake_fuse` can drive the right behavior (e.g. fabricated-precision routes to a single-IPO answer, not a blanket refusal).
- **importorskip placement:** the parametrize corpus is loaded at module import (proving the fixtures parse) BEFORE `pytest.importorskip("agent.supervisor")`, so today the module skips cleanly and once the supervisor lands it enumerates 30 cases.
- **Honest injectors:** `tool_abstain` drives `query_forecast`'s real no-band path (loader raises `FileNotFoundError`); `budget_trip` forces the P8 counter over budget so `route()` halts to synthesize — both exercise real behavior rather than neutering it.
