## Phase Goal

**As an** Indian retail investor, **I want to** ask one plain-English question and get a single honestly-cited answer across the DRHP, peers, forecast, and GMP — never advice, always terminating — **so that** I can make an informed IPO decision instead of subscribing on hype.

> This plan delivers the read-only tool surface (D-01) and the GMP-in-chat gap (D-04): the three deterministic loaders the supervisor dispatches, plus the semantic cache (D-06) that protects the free-tier quota. Storage is the integration bus — tools READ committed `data/*`, call no LLM, and burn no quota.

<objective>
Build the three read-only tool nodes (`query_peers`, `query_forecast` with GMP fold, `query_redflags`) as `retrieve.run`-shaped `SupervisorState`-in/out functions over committed `data/*` (D-01), plus the in-process semantic tool-result cache (D-06). Every loader gates `drhp_id` through the `is_known_drhp_id` allow-list before forming a path, returns the already-validated Pydantic record, honest-abstains on a missing record (never fabricates, P14), and imports NO model/LLM code.

Purpose: this is the "implement against the contracts" middle of the phase — the deterministic, quota-free capability layer the supervisor fuses.
Output: `agent/tools/*`, `agent/cache/semantic_cache.py`, isolation + loader + cache tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| drhp_id → data/* path | Untrusted id could traverse the filesystem; allow-list gate is the boundary |
| GMP display → model | GMP must stay read-only; the render/model boundary is a regulatory + integrity boundary (P4) |
| committed record → agent | data/*.json is trusted-at-rest (committed), but scraped string fields are untrusted for render |
