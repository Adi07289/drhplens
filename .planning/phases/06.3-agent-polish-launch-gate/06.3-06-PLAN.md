## Phase Goal

**As an** Indian retail investor, **I want to** ask one plain-English question and get a single honestly-cited answer across the DRHP, peers, forecast, and GMP — never advice, always terminating — **so that** I can make an informed IPO decision instead of subscribing on hype.

> This plan delivers the product's core value: the fusion of DRHP text + peers + forecast band + GMP gap into ONE cited answer where every number carries provenance (D-03) and a missing tool degrades to an honest partial (D-08). It completes the vertical slice — the supervisor now dispatches all four tools and fuses them.
