## Pattern Assignments

### `agent/supervisor.py` (orchestrator, request-response) — **the centerpiece**

**Analog:** `agent/graph.py` — copy its four load-bearing patterns verbatim in shape.

**1. Counter-bounded conditional-edge router (the P8 guard is a generalization of this).** `agent/graph.py:61-91` is the exact "counter, not cycle" pattern D-06 extends. The new `route(state)` (AI-SPEC §3 lines 204-213) is this same shape with `hops`/`tool_calls`/wall-clock in place of `regenerate_attempts`:
```python
# agent/graph.py:61-76  — the pattern to generalize
def _route_scrub(state: GraphState) -> str:
    if state.get("scrub_passed"):
        return "cite_check"
    if (
        not state.get("scrub_passed")
        and state.get("regenerate_attempts", 0) <= MAX_REGENERATE_ATTEMPTS
        and not state.get("refusal")
    ):
        return "generate"
    return "refuse_with_reformulation"
```

**2. `build_graph(checkpointer=None)` signature + `StateGraph` assembly.** `agent/graph.py:98-170`. Note `add_node` / `add_conditional_edges` / route-map dict usage (lines 111-168). The supervisor embeds the existing compiled graph AS a node — call `build_graph(checkpointer=None)` so the parent owns persistence (AI-SPEC Pitfall #2). Reuse this exact builder shape; do NOT fork it.

**3. Module-level compiled singleton.** `agent/graph.py:177` (`GRAPH = build_graph(MemorySaver())`). RESEARCH caveat (a) resolves the AI-SPEC's `SqliteSaver` sketch → **use `MemorySaver()` for the supervisor too** (fresh `thread_id` per run makes durability moot; `/tmp` is ephemeral). Compile: `SUPERVISOR = g.compile(checkpointer=MemorySaver())`.

**4. `invoke_with_tracing` entry point** — copy its `thread_id`, tracing, and crash-to-trace contract for a new `invoke_supervisor`:
```python
# agent/graph.py:214-252  — the entry-point contract to mirror
import uuid
config: dict = {"configurable": {"thread_id": f"run-{uuid.uuid4()}"}}   # MANDATORY once a checkpointer is attached (graph.py:211-214 note: this silently zeroed the numeric eval once)
...
emit_enriched_trace(question, final_state, latency_ms,
                    tool_calls=count_tool_calls(final_state), cost_usd=0.0)
flush()
```
**Delta for 6.3:** wrap the `SUPERVISOR.invoke(...)` in a `try/except GraphRecursionError` → convert to an honest partial (D-08), never re-raise a crash to the user (RESEARCH Pattern 1; caveat d). The existing `invoke_with_tracing` re-raises; the supervisor must NOT. Set `recursion_limit ≈ 50` in config as a backstop only.
