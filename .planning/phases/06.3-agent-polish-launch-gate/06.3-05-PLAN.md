## Phase Goal

**As an** Indian retail investor, **I want to** ask one plain-English question and get a single honestly-cited answer across the DRHP, peers, forecast, and GMP — never advice, always terminating — **so that** I can make an informed IPO decision instead of subscribing on hype.

> This is the first end-to-end vertical slice: the bounded supervisor wraps the existing DRHP-RAG graph unchanged and returns a synthesized, scrubbed, cited answer for a DRHP question — provably terminating. Fusion of the structured tools lands next (Plan 06); here the drhp_rag path works end-to-end under the new orchestrator.
