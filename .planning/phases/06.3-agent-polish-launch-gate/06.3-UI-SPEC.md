# Phase 6.3 — UI Design Contract

> Visual + interaction contract for the four NEW conversational/launch surfaces of Phase 6.3:
> the fused multi-tool cited answer (C1), per-number provenance chips (C2), the honest-partial
> banner (C3), and the public-launch quota/rate-limit fallback (C4). Reuses the established
> **Graphite + Amber** dark "research-terminal" design system unchanged; adds only additive
> `.drhp-fused-*` / `.drhp-prov-*` / `.drhp-partial-*` / `.drhp-quota-*` classes. All four
> elements approved element-by-element via ASCII preview on 2026-08-05 (per the user's
> granular-design-consultation rule). Existing surfaces stay AS-APPROVED (see scope fence).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Streamlit + hand-authored CSS in `app/static/drhplens.css`) |
| Preset | Graphite + Amber dark "research terminal" (established; `:root` tokens) |
| Component library | none (Streamlit primitives + `st.container(border=True)` cards + `st.expander` + inline SVG) |
| Icon library | inline SVG only (survives the Streamlit sanitizer); no icon font added |
| Font | IBM Plex Serif (display/titles) · IBM Plex Sans (body) · IBM Plex Mono (figures/labels/provenance markers) |

**Reuse mandate:** new surfaces reuse existing `.drhp-*` classes + `:root` tokens. New CSS is
additive (`.drhp-fused-*`, `.drhp-prov-*`, `.drhp-partial-*`, `.drhp-quota-*`), injected every
run via the existing `load_global_css` path. No new palette, no gradients, no red/green.

**Accent reserved for:** the expandable provenance markers on hover/focus (link affordance);

partial banner or rate-limit notice (those are **muted mono, dashed neutral border** — an
incomplete/paused state is not an error/alarm).

## Component Contracts (new — approved element-by-element via preview 2026-08-05)

### C1 — Fused multi-tool answer (`.drhp-fused-*`, D-03) — **prose-first + inline provenance chips**
- **One cohesive cited paragraph** (IBM Plex Sans body) weaving DRHP text + forecast band + peer
  comparison + the GMP-vs-model gap. NOT appended widgets; NOT labeled sections — a single
  human-reading answer.
- **Every number carries an inline superscript provenance marker** (C2); a **mono footer legend**
  under a hairline maps markers → sources (see copy above). The footer is always present on a
  fused answer.
- **GMP** appears only as the read-only GMP-vs-model **gap** with its caveat (D-04) — never as a
  model input, never green/red. The caveat sentence is mandatory whenever a GMP figure appears.
- Rendered via the existing chat answer path (`ui/snapshot_chat.py`) using
  `st.markdown(..., unsafe_allow_html=True)` with a single `<div class="drhp-fused">…`; markers
  are `<sup class="drhp-prov …">`. Sanitizer-safe (no script; inline SVG only if needed).
- **States:** loading = existing "thinking" spinner (unchanged); nothing-grounded = existing
  refusal (unchanged); one-tool-missing = C3 partial banner + the fused prose for the rest.

### C2 — Per-number provenance chip (`.drhp-prov-*`, D-03/D-04) — **distinct markers, tap-to-expand**
- **DRHP-grounded numbers** keep **numbered** superscripts (`¹ ² ³ …`) → expand to the DRHP span
  + `[open page]` (the EXISTING citation-expander behavior; reuse `ui/expander.py`
  `render_citation_expanders` — do NOT rebuild).
- **Tool-derived numbers** get **letter** superscripts — `ꜰ` forecast, `ᴾ` peers, `ᴳ` GMP → expand
  to a one-line source descriptor + a link to that surface (copy above). Doc-grounded vs
  data-grounded is distinguishable **at a glance** (the honesty payoff: a forecast number visibly
  is model-derived, not from the DRHP).
- All markers: IBM Plex Mono, muted by default, **accent on hover/focus** (link affordance),
  keyboard-focusable. Expansion reuses the existing `st.expander` / citation-expander mechanism
  (no live LLM/Qdrant call on expand — reads the cached answer object, mirroring the Phase-3
  methodology-pane `inspect.getsource` no-client rule).
- Every `FusedClaim` must populate `source_tool` + `source_record_id` so the marker resolves to a
  real committed record; a number with no resolvable source must not render (fail cite-check
  instead — AI-SPEC §5, FM-3).

### C3 — Honest-partial banner (`.drhp-partial-*`, D-08) — **neutral banner ABOVE the answer**
- A **muted mono strip with a dashed neutral border** (reuse the disclaimer / `.drhp-fail` muted-
  dashed styling) sits **above** the grounded+cited partial content, naming what's missing.
- Two copy variants (above): single-tool abstain/error (source-specific) and budget-trip. The
  content below is scrubber-clean + cite-checked; the banner NEVER accompanies a fabricated
  gap-fill.
- **Not** red/alarm — an incomplete answer is honest, not an error. Eyebrow `INCOMPLETE ANSWER`
  in mono uppercase; body in Sans.
- Carries a stable `is_partial` state hook so a render test can assert the banner shows iff the
  agent set `is_partial=True` (AI-SPEC §5 honest-partial dimension).

### C4 — Quota / rate-limit fallback (`.drhp-quota-*`, D-12) — **fallback card replaces chat input**
- **Daily-cap exhausted:** the chat input is **replaced** by a muted card (`st.container`,
  dashed neutral border) — heading (Serif) + body routing to the always-working read-only
  surfaces (snapshot/forecast/peers, `/methodology`, `/failures`) + a `▶ Recorded chat
  walkthrough` link. The rest of the app stays fully usable (P19 read-only surfaces are LLM-free).
  **Not** a full-page interstitial — must never block the portfolio surfaces a recruiter came for.
- **Transient rate-limit (per-session/IP):** the input STAYS enabled; a brief **muted inline
  notice** appears above it ("You're sending questions quickly — try again in a few seconds."),
  non-blocking, auto-clears.
- Surface/walkthrough links are accent (link affordance). No countdown alarm styling; a soft
  "resets later today" tone. Copy tone matches 06.2's live-demo-placeholder.
- **States:** normal (input active, no notice) · rate-limited (input active + inline notice) ·
  cap-exhausted (input replaced by card). The three are mutually exclusive.

## Honesty Checks (non-negotiable — this is a portfolio whose thesis is honesty)

- [x] No red/green/alarm color on any new surface (partial banner + rate-limit notice are muted mono/dashed, not error-red).
- [x] Every fused number carries a resolvable provenance marker; an unresolvable number fails cite-check rather than rendering (C2).
- [x] GMP renders only as the read-only gap + mandatory caveat; never as a model feature, never color-coded (C1/D-04).
- [x] The partial banner never accompanies a fabricated gap-fill; missing = named, not invented (C3/D-08).
- [x] Compliance-bait / advice questions reuse the existing no-advice refusal copy — no new advice-adjacent string introduced (D-07a).
- [x] Quota fallback degrades gracefully to the honest read-only surfaces; never fabricates a "cached" live answer (C4).
- [x] Forecast provenance labels it "GMP-free model · calibrated backtest" — consistent with the honest model card (does-not-beat-baselines), no overclaim.
- [x] Tap-to-expand reads the cached answer object only — no live LLM/Qdrant call at expand (P19 demo-safe, mirrors the methodology-pane no-client rule).
- [x] All new copy centralized in `ui/copy.py` (extend, don't inline) so the banned-token scrubber's import-time assertion covers it.
