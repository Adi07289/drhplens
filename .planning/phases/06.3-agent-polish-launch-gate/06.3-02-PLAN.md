## Phase Goal

**As an** Indian retail investor, **I want to** ask one plain-English question and get a single honestly-cited answer across the DRHP, peers, forecast, and GMP — never advice, always terminating — **so that** I can make an informed IPO decision instead of subscribing on hype.

> This plan delivers the routing brain: the single bounded LLM-classify hop (D-05) that decides which read-only tools a question needs, with the jailbreak-resistant prompt discipline that makes the launch gate defensible.

<objective>
Build `agent/nodes/classify.py` — the ONE bounded LLM-classify hop (D-05) that proposes a tool set (clamped to the allow-list so the model cannot invent a tool) and flags `is_advice_seeking`/`is_out_of_scope` so compliance-bait and gibberish short-circuit to a graceful refusal with no tool thrash (D-07a/c). Mirrors `agent/nodes/decompose.py` almost 1:1 (Instructor + google-genai + GEMINI_MODELS failover + T-1-01 system/user separation).

Purpose: routing is the first line of the P8 + compliance defense — reproducible (the stress suite asserts on it) and structurally jailbreak-resistant.
Output: `classify.py`, `classify.md` prompt, unit tests. LLM is stubbed in tests (no live call).
</objective>
