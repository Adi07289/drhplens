## Decisions Made

- **Stress gate GATES deploy, advice-by-implication does NOT.** The `sys.exit(1)` lane asserts only the deterministic envelope; advice-by-implication is a separate REPORTED judge lane (AI-SPEC §5) and the report says so — a regex cannot catch a clean-token lean, so gating it would be evaluation theatre.
- **Offline-first ordering.** The two deterministic gates (eval + stress) run before the live numeric gate, so an already-committed regression blocks deploy without touching live infra.
- **All-skipped is a breach.** `run_stress_suite` requires `passed_count >= 1`; `returncode == 0` alone would let an importorskipped/empty suite silently pass the offline gate.
- **Stable Langfuse codes.** FAILURE_MODES is append-only because the numeric score is the 1-based index; reordering would break saved Cloud views.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] Guard the offline gate against a silent all-skipped pass**
- **Found during:** Task 2 (`run_stress_suite` / `_parse_pytest_summary`)
- **Issue:** pytest returns exit code 0 when every test is skipped (or none is collected). A naive `passed = returncode == 0` would let an importorskipped or empty stress suite silently PASS the offline deploy gate — the exact false-green a deploy gate must never emit.
- **Fix:** `_parse_pytest_summary` sets `passed` True only when `returncode == 0` AND `failed == 0` AND `errors == 0` AND `passed_count >= 1`; a dedicated unit test (`test_parse_all_skipped_is_not_a_pass`) pins it.
- **Files modified:** `scripts/release_gate.py`, `tests/unit/test_release_gate_stress.py`
- **Verification:** unit test green; integration spot-check confirmed the real green suite passes and a synthetic breach exits non-zero.
- **Committed in:** `ce4bcd0` (Task 2 commit)
