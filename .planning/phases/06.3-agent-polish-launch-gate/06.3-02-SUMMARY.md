# Phase 6.3 Plan 02: Bounded Classify Hop Summary

**The routing brain: one bounded LLM-classify hop (Instructor + google-genai, -lite-first failover) that proposes a tool set a deterministic allow-list clamps (D-05), flags advice/out-of-scope to short-circuit compliance-bait and gibberish (D-07a/c), and is structurally jailbreak-resistant by passing the raw question only as a user-role message (T-1-01).**

## Accomplishments

- **D-05 bounded routing** — `agent/nodes/classify.py` clones `decompose.py` almost 1:1: `RoutingDecision(BaseModel)` with a `ToolName = Literal["drhp_rag","query_peers","query_forecast","query_redflags"]` union (`tools` defaults empty, `max_length=4`) plus `is_advice_seeking` / `is_out_of_scope` flags. `_llm_classify` uses `instructor.from_genai(..., Mode.GENAI_STRUCTURED_OUTPUTS)` with a `@retry(stop_after_attempt(3))` wrap and a `reversed(GEMINI_MODELS)` failover loop so the cheaper `-lite` model runs first. Flat `temperature=0, max_tokens=256` kwargs (RESEARCH caveat b — Instructor owns the `config`).
- **Deterministic clamp (the authority boundary)** — `run()` computes `plan = [t for t in decision.tools if t in ALLOWED_TOOLS]`; a hallucinated name that slips past the schema (proven via `model_construct`) is dropped before it can reach the dispatcher. The LLM proposes; the allow-list decides (D-05).
- **D-07a/c short-circuit** — when `is_advice_seeking` or `is_out_of_scope` is set, `run()` forces `tool_plan == []` so compliance-bait / gibberish / jailbreak / cross-IPO refuse downstream with no tool thrash. On total LLM failure the hop degrades to an empty plan, never a crash (D-07c). `hops` always += 1.
- **T-1-01 jailbreak defense** — the raw user question is passed ONLY as the `user`-role message; the system content is the loaded `classify.md` with no f-string / `.format` / concatenation of the question. Verified by grep that no interpolation exists.
- **classify.md four-category few-shot** — an informational/educational classifier framing with inline exemplars for all four D-07 categories (advice-bait → `tools=[]`, `is_advice_seeking=true`; jailbreak → `is_out_of_scope=true`; off-topic/gibberish → `is_out_of_scope=true`; cross-IPO/compare → `is_out_of_scope=true`). The prompt never restates the raw question and emits no prose answer; a loader test asserts the four category cues AND zero banned prescriptive tokens.

## Decisions Made

- **`reversed(GEMINI_MODELS)` for classify only.** `decompose.py` keeps flash-first; classify is the highest-frequency hop, so the cheaper `-lite` model is tried first for free-tier quota (RESEARCH §4b). Documented inline.
- **`ALLOWED_TOOLS` as a separate `frozenset` clamp, not merely the Literal.** The union bounds a schema-valid proposal, but the deterministic clamp in `run()` is the authority boundary — proven by a `model_construct` test that drops a hallucinated name. This is the D-05 "LLM cannot invent a tool" guarantee made structural, not incidental.
- **Banned-token-free classifier framing.** The prompt cues all four D-07 categories using non-prescriptive vocabulary (advice/verdict/opinion/price-prediction/apply/exit), verified by running `compliance.scrubber.scrub` over the whole prompt in a test — so a classifier prompt can never itself leak prescriptive language.
