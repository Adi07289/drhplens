# Phase 06.3 Plan 08: Fused-Answer UI Surfaces C1/C2/C3 + Supervisor-Routed Chat Summary

**The fused answer is now visible: a render-only prose-first cited paragraph (C1) where every number carries a provenance marker distinguishable at a glance — DRHP claims numbered (reusing the existing citation expander), tool numbers lettered ꜰ/ᴾ/ᴳ/ᴿ (C2) — with a muted-dashed neutral honest-partial banner (C3) and GMP shown only as the caveated read-only gap (D-04); the production chat now drives the multi-tool supervisor and renders these fused answers, all read-only with no live LLM/Qdrant call on render or expand (P19).**

## Accomplishments

- **C1 fused answer (D-03)** — `ui/fused_answer.py` renders one cohesive `<div class="drhp-fused">` prose-first cited paragraph via `st.markdown(unsafe_allow_html=True)`, with an always-present mono footer legend (`.drhp-fused-legend`) mapping every marker → its source. Escape-then-interpolate (mirrors `ui/chip.py`) keeps it sanitizer-safe.
- **C2 provenance chips (D-03/D-04)** — DRHP-grounded `Claim` numbers get NUMBERED superscripts and REUSE `ui.expander.render_citation_expanders` UNCHANGED (wrapped in a Claim-only `GroundedAnswer`); tool-derived `ToolClaim` numbers get LETTERED superscripts (ꜰ forecast / ᴾ peers / ᴳ GMP / ᴿ red-flags) via a sibling descriptor path expanding to a one-line source descriptor + surface link. Doc-vs-data is legible at a glance. A `ToolClaim` with no resolvable claim (dropped at cite-check, FM-3) renders NO marker.
- **C3 honest-partial banner (D-08)** — a muted mono `.drhp-partial` strip with a DASHED NEUTRAL border + `INCOMPLETE ANSWER` eyebrow renders ABOVE the answer iff `is_partial=True`; two copy variants (source-specific tool-abstain vs generic budget-trip, chosen via the `unaddressed` step-budget sentinel). Never red/alarm; never accompanies a fabricated gap-fill.
- **D-04 GMP framing** — a GMP number carries the ᴳ marker (detected via the `source_record_id` `gmp_gap` field-path, since GMP folds into `query_forecast`) and its expander body is the mandatory display-only caveat ("GMP is an informal grey-market figure … never enters the model") — never colour-coded, never a model feature.
- **Supervisor-routed chat (D-02/D-03)** — `ui/snapshot_chat.py`'s new `_invoke_agent` routes the production chat through `agent.supervisor.invoke_supervisor` (the multi-tool bounded agent) instead of the Phase-1 single-tool `invoke_with_tracing`, resolves `fused_answer > grounded_answer > refusal`, and renders a `FusedAnswer` via `ui.fused_answer.render_fused_answer` + the preserved per-answer disclaimer. Prior `GroundedAnswer`/`RefusalResponse` turns still render (shape compatible).
- **Copy + CSS + tests** — all C1/C2/C3 strings centralized in `ui/copy.py` (import-time scrubber covers them; reuses `REFUSAL_BANNED_TOKEN_COPY`, no new advice-adjacent string); additive `.drhp-fused*/.drhp-prov*/.drhp-partial*` CSS uses only `--drhp-space-*` tokens with a no-verdict-palette grep guard; the render-only contract is pinned by an AST import-allowlist + forbidden-token scan (mirrors `test_eval_inline.py`).
