# Phase 6.3 Plan 03: Read-only Tool Surface + GMP Fold + Semantic Cache Summary

**Three deterministic `retrieve.run`-shaped read-only tool nodes (peers / forecast+GMP-gap / red-flags) over committed `data/*.json` that call no LLM and burn no quota, plus an in-process per-IPO TTL + cosine-dedup semantic cache — with an `inspect.getsource` audit pinning the tools as model-free and GMP display-only.**

## Accomplishments

- **D-01 read-only tool surface** — `agent/tools/{query_peers,query_forecast,query_redflags}`, each a plain `SupervisorState`-in/out node in the shape of `agent/nodes/retrieve.run`. Every node gates `drhp_id` through `is_known_drhp_id` BEFORE any `data/*` path (T-6.3-PATH), loads the already-validated Pydantic record via the existing loader (`load_peers` / `load_forecast` / `load_redflag`), appends a provenance-tagged `tool_results` entry (`{tool, record, provenance, abstain}`), pops itself from `tool_plan`, increments `tool_calls` by exactly 1, and returns via `{**state, ...}`. No LLM, no quota — storage is the integration bus.
- **P14 honest abstain** — a missing record (FileNotFoundError) yields `record=None, abstain=True, provenance=None` with no exception; an unknown/traversal id is a distinct hard rejection (ValueError) before any read.
- **D-04 GMP fold** — `query_forecast` additionally reads `data/gmp/<id>.json` via the display-only `GmpRecord` and, ONLY when a premium is reported, adds a `gmp_gap` block (quotes + spread + the GMP-free `model_band_pct` reference + the mandatory `ui.copy.GMP_CAVEAT`). Absent GMP omits the fold (no fabricated gap); the GMP value never enters a model field.
- **D-06 semantic cache** — `agent/cache/semantic_cache.cached_answer(drhp_id, question, embed, compute)`: a per-`drhp_id` bucket (no cross-IPO leakage by construction), TTL sweep at `CACHE_TTL_S`, cosine ≥ `DEDUP_THRESHOLD` dedup, `threading.Lock`-guarded store, injected embedder (no new dependency). Best-effort, lost on cold start; caches the quota-scarce LLM hops, NOT the static loaders.
- **Isolation pin** — `tests/unit/test_tools_isolation.py` (mirrors `test_gmp_isolation`) audits each tool's source for zero model/LLM tokens and pins GMP as display-only in `query_forecast`.

## Decisions Made

- **Static loaders = plain read, not semantic cache.** RESEARCH Pattern 3 anti-pattern: the tool loaders are a pure function of `(tool, drhp_id)`, so they do a cheap committed-file read. The semantic cache is reserved for the quota-scarce LLM hops (classify / DRHP-RAG / synthesis) and is delivered here as a standalone module for those consumers (06.3-05/06).
- **Explicit top-of-node allow-list gate** in addition to the loader's own gate — makes the T-6.3-PATH boundary visible in the tool source (satisfies the plan key_link `agent/tools/* → is_known_drhp_id`) and cleanly separates "unknown id → ValueError (rejected)" from "known id, missing file → honest abstain".
- **Reused `ui.copy.GMP_CAVEAT`** (a streamlit-free import) for the gap caveat rather than duplicating the string — the codebase explicitly protects GMP/compliance copy stability; the canonical caveat already states GMP is "never used in any forecast".
- **Isolation token list** deliberately excludes the data-domain words (`forecast`/`peers`/`redflag`/`gmp`) the tools legitimately read, and drops the bare `shap` token (collides with "shape" in the docstrings; SHAP is already implied-forbidden via the modelling-library tokens).
