## Sampling Rate

- **After every task commit:** Run `pytest tests/unit -q` (+ the touched module's tests)
- **After every plan wave:** Run `pytest -q` (full offline suite, no wedge)
- **Before `/gsd-verify-work`:** Full suite green + the new stress suite green + `scripts/release_gate.py` passes
- **Max feedback latency:** ~120 seconds (offline suite has historically wedged only on unguarded live paths — keep the `--run-*` gates)
