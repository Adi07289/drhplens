# Phase 06.1 Plan 05: Deterministic Eval Release Gate Summary

**Extends `scripts/release_gate.py` with a pure `enforce_eval_gates()` that hard-blocks deploy on `citation_accuracy < 0.95` OR `recall@10 < 0.85` (read from the committed `eval_summary.json` via the shared `EvalSummary` schema), keeps `faithfulness_deepeval` reported-only, and preserves the unchanged live numeric-faithfulness gate.**

## Accomplishments
- Added `CITATION_ACCURACY_GATE = 0.95` and `RECALL_AT_10_GATE = 0.85` to `agent/policies.py` beside `NUMERIC_FAITHFULNESS_GATE`, each with an "enforced, not a tunable to relax" docstring; the recall docstring labels it a regression FLOOR ratified against the spike-003 1.00 baseline (P10).
- Added a PURE `enforce_eval_gates(summary, report_dir=None)` to `scripts/release_gate.py` mirroring `enforce_gate`: computes `passed = citation_accuracy >= gate AND recall@10 >= gate`, writes a dated `<date>-eval-gate.md` report on BOTH branches, and `sys.exit(1)` with a precise breach message when not passed. No live-infra import — unit-tested offline on injected `EvalSummary` values.
- `faithfulness_deepeval` is written to the report under a "Reported (NOT gated)" section with a `>= 0.95 target` line and `-1` "not measured" sentinel handling; it NEVER affects the exit code (T-6.1-16).
- Wired both gates into `main()`: the offline deterministic eval gate reads the committed `eval/reports/eval_summary.json` via `EvalSummary.model_validate_json(...)`, then the unchanged live numeric `enforce_gate` still runs. Neither gate removed.

## Decisions Made
- **recall@10 stays a labelled regression floor, not a headline** — enforced at 0.85 but documented (constant docstring + report interpretation) as saturated at 1.00 on the current coarse gold spans (spike 003). This mirrors AI-SPEC §5 and P10 honesty invariant.
- **faithfulness never gates** — the DeepEval LLM-judge is non-deterministic run-to-run; hard-gating it is itself a flaky-gate failure mode (T-6.1-16). It renders a target line for context only, with the `-1` sentinel shown as "not measured".
- **Deterministic gate runs first, offline** — so a committed regression blocks the build before any live-infra call; the live numeric gate follows unchanged.
- **Shared schema, no re-derivation** — the gate parses the runner's committed artifact through `eval.metrics.EvalSummary` (T-6.1-15); report and gate can never diverge.
