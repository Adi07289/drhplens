## Critical Gaps (must fix before production)

1. **[CRITICAL] Faithfulness dimension is unmeasured and the judge is uncalibrated.** The DeepEval wrapper exists and honestly reports `-1`, but there is no committed faithfulness number and the **≥50-example / ≥0.7 judge-vs-human calibration is not done** (quota-blocked). Until calibration passes, the system's central RAG-quality dimension (groundedness) has no measured, trustworthy signal. *Honest, but incomplete — this is the gate to actually trusting the judge.*
2. **[CRITICAL] The P10 ≥50-example human spot-check was not performed, yet deterministic figures are surfaced inline.** AI-SPEC §5/§7 call this the "non-negotiable calibration step before any figure is surfaced." recall/citation figures render on every IPO page without it. Both are saturated at 1.00 on coarse spans, so the risk of surfacing a hollow "win" is live (mitigated in copy by the honesty caveat, but the human confirmation is still owed).
3. **[CRITICAL] No automated CI gate lane.** The release gate is a manual `make release` only; no GitHub Actions workflow blocks a PR/push on citation/recall/numeric regressions. Enforcement currently depends on developer discipline — the exact failure mode the gate was built to prevent ("enforcement over discipline").

_Closed since the 60/100 audit:_ **Production queries are now traced** (`ui/snapshot_chat.py` → `invoke_with_tracing`), so the Langfuse enrichment + failure-mode taxonomy now have a production data source. This gap is resolved (pending a regression test + the 6.2 cloud-verification handoff).
